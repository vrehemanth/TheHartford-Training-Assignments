TASK 1: Form Not Submiƫng (HTML + JS)
Buggy Code:

    <form id="userForm">
        <input type="text" id="username">
        <button onclick="validate()">Submit</button>
    </form>
    <script>
    function validate() {
        let name = document.getElementById("username").value;
        if (name == "") {
        alert("Name required");
        }
    }
    </script>

Solution 1: (Prevent form from submit)
    <form id="userForm">
        <input type="text" id="username">
        <button type="button" onclick="validate()">Submit</button>
    </form>

    <script>
    function validate() {
        let name = document.getElementById("username").value;

        if (name === "") {
            alert("Name required");
        } else {
            alert("Form submitted");
        }
    }
    </script>
